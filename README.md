# 📝 Todo WebApp

**Todo WebApp** là dự án học full-stack giúp quản lý công việc hàng ngày với các chức năng tạo, sửa, xóa, đánh dấu hoàn thành nhiệm vụ. Dự án luyện tập kỹ năng **full-stack** với **Node.js + MongoDB** cho backend và **React.js + TailwindCSS + ShadCN** cho frontend, deploy trên **Render**.

## 🚀 Tính năng

- Tạo, chỉnh sửa, xóa nhiệm vụ  
- Đánh dấu nhiệm vụ hoàn thành  
- Bộ lọc công việc:  
  - Tất cả  
  - Hoàn thành / Đang làm  
  - Theo hôm nay, tuần, tháng  
- Giao diện trực quan, responsive

## 🛠 Công nghệ sử dụng

- **Frontend:** React.js, TailwindCSS, ShadCN  
- **Backend:** Node.js, Express.js, MongoDB  
- **Deployment:** Render  
- **Tools:** VSCode, Postman (kiểm tra API)

## ⚡ Cách chạy dự án

//backend
```bash
cd backend
npm install
cp .env.example .env   # điền thông tin MongoDB
npm run dev

//frontend
```bash
cd frontend
npm install
npm run dev
